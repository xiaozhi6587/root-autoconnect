# 使用说明

## 启动

运行 EXE 前，将同名 `.exe.config` 文件与其放在同一目录。电脑需要 .NET Framework 4.7.1 或更高版本，并有可正常运行的 USB Redirector Technician Edition。

首次打开默认暂停。程序会自动寻找 `usbtechsh.exe` 并只读扫描设备；点击“开始自动连接”后，才会对符合规则的设备发送连接请求。

## 自动定位

按已保存路径、运行进程、32/64 位的当前用户和整机安装记录、App Paths、快捷方式、常见目录、PATH 以及固定磁盘补充搜索等来源定位。查找有约 15 秒的时间限制和目录数量限制。

路径失效时会重新定位。也可展开“连接设置”，点击“自动定位”或“浏览”手动指定 `usbtechsh.exe`。没有安装、文件被移除、权限不足或放在搜索跳过的目录中时，可能需要手动选择。

## 筛选和排除

- 筛选框留空时匹配全部可用设备；输入文字按名称、VID/PID、序列号、USB 端口、编号或地址包含匹配，不区分大小写。
- 右键“不自动连接此设备”加入排除名单；右键可恢复、查看信息，或打开排除管理。
- 管理窗口支持多选并恢复，即使设备暂时离线也能管理已有规则。
- 排除名单保存后立即作用于后续请求，重启仍生效；不会断开已经建立的连接。

排除规则使用远程主机、VID/PID 和序列号；没有序列号时使用 USB 端口，再没有端口时使用设备名称。临时列表编号和回连 TCP 端口变化不影响规则。远程主机或匹配字段改变后需要重新排除；同一主机上缺少序列号及端口、且名称和 VID/PID 相同的设备会一并匹配。

## 扫描与重试

默认扫描间隔为 2 秒，范围 1–60 秒；默认重试间隔为 15 秒，范围 5–600 秒。连接前再次读取列表，核对身份、排除规则和状态。已连接、正在连接、离线及未知状态的设备不触发连接。

“已连接”取自重新扫描的实际状态，提交命令成功不等于已经连接。“USB口”来自技师端输出的 USB 端口字段，不是 COM 端口。

停止或关闭助手只停止后续扫描和连接请求，已经建立的连接保留；已经提交的请求可能仍会由技师端完成。

## 主题与日志

月亮切换深色，太阳切换浅色，设置会保存。颜色渐变约 280 毫秒、图标过渡约 240 毫秒；关闭 Windows 界面动画时直接切换。

日志正文为 14 号半粗字体：蓝色操作、绿色成功、橙色提醒、红色错误。界面保留最近 150 条。程序设置、按日期保存的日志及异常诊断 `startup-error.log` 位于 `%LOCALAPPDATA%\UsbAutoConnect`。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 没找到技师端 | 先运行技师端，再点击“自动定位”，或浏览安装目录选择 `usbtechsh.exe` |
| 没有设备 | 确认 Customer Module 已接入技师端 |
| 命令执行失败 | 检查技师端服务、许可、网络及运行权限，并查看原始输出 |
| 设备被跳过 | 检查筛选内容和排除名单 |
| 列表格式不支持 | 当前适配 1.9.7.3130 的英文命令行格式，保留原始输出用于排查 |
| 启动提示异常 | 保留同名配置文件，并查看 `startup-error.log` |

该工具只负责调用原厂命令行自动连接设备；设备驱动、许可、网络及固件操作仍由原厂软件或相应维护工具负责。
